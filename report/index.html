    5 · Methods

    Sources. Experiment tables of five combustion investigations in NASA's Physical Sciences Informatics (PSI) repository, released under CC0. Each table row is one test. Investigation metadata (titles, people, dates, hardware, publication counts, dataset DOIs) comes from the PSI investigation records.

    Variable mapping and units. Columns were mapped to shared variables: oxygen given as mole fraction (FLEX, CFI) was converted to percent by volume; pressure in mmHg (FLEX) was multiplied by 0.133322 and pressure in atm (CFI) by 101.325 to obtain kPa. SAFFIRE reports oxygen as approximate values or ranges (for example "21.5 – 21.7"); the lower bound is used and those tests carry grade B.

    Neighbourhood and distance. A test is in the scenario neighbourhood when its O₂ is within the selected tolerance (default ±4 points) and its pressure within the selected factor (default ×1.25) of the scenario. Ranking uses d = √[(ΔO₂/τO₂)² + (ln(P/Ps)/ln τP)²], so d ≤ 1 is roughly inside the neighbourhood. For tests without recorded pressure, d uses oxygen only and is reported separately.

    Data quality.

    Scope of this prototype. This report is built from experiment tables only. In the full Prometeo pipeline the variable schema is induced from the corpus, values missing from tables (such as chamber pressure for solids) are extracted from reports and papers with verbatim citations, and relations stated by authors are added as cited evidence. Until then, statements here are limited to what the tables record.

    Reproducibility. All numbers in this page are computed in the browser from data.js, which is generated by tools/build_data.py from the downloaded PSI tables. Change the scenario or tolerances and every figure, table and sentence updates.
